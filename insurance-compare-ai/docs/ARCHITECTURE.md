# 보험상품 비교 AI 어시스턴트 - 서비스 아키텍처

## 1. 시스템 개요

보험 설계사가 자연어로 질문하면, 매월 업데이트되는 보험상품 비교 PDF 데이터를 기반으로
정확한 비교 결과를 구조화된 형태로 답변하는 AI 어시스턴트.

## 3. 데이터 흐름

### 3-1. PDF 업로드 → 구조화 (월별 갱신)
```
PDF 파일 → Supabase Storage 업로드
         → Edge Function 트리거
         → pdf-parse로 텍스트 추출
         → 페이지별 섹션 분리 (정규식)
         → 표 데이터 → JSON 구조화
         → comparison_rows 테이블 UPSERT
         → documents 메타데이터 업데이트
```

### 3-2. 질문 → 답변 (실시간)
```
사용자 질문 입력
  → 질문 파서 (조건 추출)
     - 상품군: 장기종합보험, 종신보험 등
     - 성별: 남/여
     - 나이: 40세, 50세 등
     - 보험형태: 일반형, 무해약형, 건강고지 등
     - 보험사: 삼성, 한화, DB 등
     - 비교항목: 암진단비, 보험료, 납입면제 등
  → 조건 누락 검사 (필수: 상품군)
  → comparison_rows 테이블 검색/필터
  → 비교 엔진 (정렬, 순위, 차이점 분석)
  → 답변 포맷터
     - 질문 해석 결과
     - 한줄 결론
     - 비교표 (HTML 테이블)
     - 추천 포인트
     - 주의사항
     - 출처 페이지
  → 프론트엔드 렌더링
```

## 4. 기술 스택

| 구분 | 기술 | 이유 |
|------|------|------|
| Frontend | HTML/CSS/JS (아임웹 삽입형) | 아임웹 body 직접 삽입 |
| Backend | Supabase Edge Functions (Deno) | 서버리스, 무료 티어 |
| DB | Supabase PostgreSQL | 구조화 검색, RLS |
| Storage | Supabase Storage | PDF 원본 보관 |
| AI/LLM | Claude API | 질문 해석, 요약 생성 |
| PDF 파싱 | pdf-parse + 커스텀 파서 | 표 구조 추출 |

## 6. MVP 범위 (1단계)

- **대상 상품군**: 장기종합보험 (암보험 비교)
- **핵심 기능**: 
  - PDF → 구조화 데이터 변환
  - 자연어 질문 → 조건 추출
  - 비교표 생성 및 답변
- **지원 비교항목**:
  - 암진단비 (일반암/유사암/소액암)
  - 항암치료비
  - 수술비
  - 납입면제 조건
  - 보험료
  - 가입나이 범위
- **지원 필터**:
  - 보험사
  - 성별/나이
  - 보험형태 (일반형/무해약형)
